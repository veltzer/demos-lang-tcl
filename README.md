# demos-lang-tcl

Demos for the Tcl language.

## Layout

- `examples/` - short demos grouped by topic: arrays, control flow, procs,
  namespaces, regexps, files and I/O, error handling and exceptions, eval,
  environment, multi-processing and Tk.
- `exercises/` - exercises (`*.txt`) with matching solutions (`*.tcl`).
- `doc/` - links to Tcl resources.
